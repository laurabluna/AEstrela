# AEstrela

Projeto em Java com implementação do algoritmo A* (A-estrela).

**Descrição:**

- Implementação do algoritmo de busca A* para resolução de problemas de caminho.
- Contém utilitários de leitura e o algoritmo principal em Java.

**Arquivos principais:**

- `algoritmo.java` — implementação do algoritmo A*.
- `leitor.java` — classes/funções para leitura de entrada (mapas, grafos, etc.).

**Requisitos:**

- Java JDK 8 ou superior instalado.

**Compilar:**

Abra um terminal na pasta do projeto e execute:

```bash
javac algoritmo.java leitor.java
```

**Executar:**

Após compilar, rode a classe principal. Exemplo (substitua `MainClass` pela classe com o método `main` caso seja diferente):

```bash
java MainClass
```

Se o arquivo `algoritmo.java` contiver o método `main`, execute:

```bash
java algoritmo
```

**Uso:**

- Forneça a entrada no formato esperado pelo `leitor.java` (arquivo, stdin, etc.).
- Ajuste parâmetros dentro do código, se necessário (heurística, custo, etc.).
